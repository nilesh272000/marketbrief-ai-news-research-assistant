# Security and responsible use

- Store keys in `.env` or Streamlit secrets; never commit secrets.
- Respect publisher terms, robots policies, rate limits, copyright, and access restrictions.
- Do not bypass paywalls, login walls, bot challenges, or publisher controls.
- Retrieved article text is untrusted and may contain prompt-injection attempts. Prompt instructions are mitigation, not a complete security boundary.
- Do not ingest confidential or regulated data without authorization and controls.
- Production requires authentication, tenant isolation, encryption, secrets management, request limits, audit logs, and human review for consequential financial decisions.
